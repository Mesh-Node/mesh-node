# inbox

Packets land here. One short markdown file per note.

```
who: who it is for
what: what to do
files: which files (or none)
```

Files stay on disk. The note is not the files.

Name the file after the computer: `inbox/<this-computer>.md`. Lowercase. One packet per file.

A packet names files. It does not carry them. Do not put `procedure-state.md`, mounts, or home paths in the inbox.
