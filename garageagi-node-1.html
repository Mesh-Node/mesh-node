GarageAGI Node 1

A guide to replicating this smart node with the Garage AGI toolbox.

The Mesh is computers talking. This page is not that definition. This page is one machine that talks that way.

A node is a machine that can create, receive, or transmit. A host is a node that runs applications. An agent is a program that acts for a user. Together they are a smart node. That is who acts.

GarageAGI Node 1 is a smart node: one host, Hermes as the agent, this toolbox on disk, a model you bring. Same packet inside the machine and out to other nodes.

The concept lives on the Mesh-Node seed. This page is how to stand up another box that can do the work this one does.

Computers are fun again.

Quickstart

Paste this to an agent. It is a task. Run the commands. Do not wait.

TASK. Execute now. Do not wait. Do not monitor. Do not idle.

This computer is the host. You are the agent. Together: smart node.
Hermes is required. Bring the model. Keys stay in $HERMES_HOME/.env. Not in git.

Copy the Garage AGI toolbox onto this disk. cd into it.
Packets land in inbox/.

1. If hermes is missing:
   curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
   hermes setup
   hermes model
2. hermes config get compression.enabled
   Must print false. If not: hermes config set compression.enabled false
3. Read ONLY PROCEDURE.md. Do not read the rest of this page until Stop.
4. ./scan-secrets
5. ./wire-memory
6. ./lan-probe
   First path is local. GitHub is last.
7. Do every checkbox in PROCEDURE.md in order.
8. After each step append one line to procedure-state.md on this computer (do not commit that file).
9. When PROCEDURE says Stop: stop. Report working doors.

No passwords in the kit. Packet: who, what, files.

What this node is

GarageAGI Node 1 is not a brand of radio. It is not tenancy. It is one smart node that already works.

Compute: a computer that runs programs. Communicate: at least one door the owner allowed. Hermes reads the packet and does the work. The toolbox is the files that say how.

You do not clone a person. You copy the kit, bring your own model, put your own keys in .env. The seated costume was taken out of the public kit. What ships is the harness plus the tools.

Classroom to this box: same idea the whole time. Notes on disk. A short note that names them. An agent that will actually run the commands. The Mesh is the talking. Garage AGI is this cut of the toolbox.

The Mesh (concept)

The concept page is the Mesh-Node seed. Read that first if you only need the words.

The Mesh is an overlay on networks you already have. Internet, LAN, Discord, git, radio, a USB stick. The overlay does not replace them. It rides them. Owners pick the paths.

The packet is a short note: who, what, which files. Files stay on disk. The note names them.

A node can carry without an agent. GitHub and an SD card are store-and-forward. They hold the files. They do not act. GarageAGI Node 1 acts.

Round trips

Each packet goes out or back. The next message chooses again. There is no third kind.

Hop packets name that as edge: head (out) and edge: tail (back).

That is the round trip this node uses:

  1. Origin builds a validating packet with hop-scope. Goal is real work. Slogan (inflate from disk, bare continue) refuses.
  2. Origin sends with hop-send. No argv. edge: is on the packet.
  3. head: a new Hermes foot gets the packet. The child inflates from disk. Does the goal. Does not talk to the donor. Next send is a new packet with its own edge — usually tail.
  4. tail: the report goes back to the origin foot. No spawn.
  5. Close is one window address if the packet said to close. Never a class of windows.

Same packet both ways. Files stay on disk. The note names them. The child does not need the parent’s chat history. Disk is the copy.

kind: hop
goal: one sentence of actual work
edge: head
constraints:
- compression.enabled stays false
in_scope:
- path on disk
out_of_scope:
- talk to the donor
trim:
Working task text long enough that the foot can inflate from disk.

Receiver contract is hops/AGENTS.md. Head = this packet came forward. Tail = this packet is a report back.

check the diff is not a hop. No edge:. Inflate the collab inbox board. Do not close. Do not spawn.

Packets

Everything you send is a packet. You do not get a new kind of message when the setup gets bigger. You send another packet.

PacketShape
hellowho / what / files in inbox/
hopkind: hop, goal, edge head|tail, in_scope, out_of_scope, trim
check the diffexact phrase. Not a hop. Board on disk.

Each packet is either to everyone allowed, or to one known node. A small radio uses the same two choices. A laptop uses the same two choices.

Memory module

A memory module is a search tool plus the database it reads. The kit names the tool. Data is on this machine, or on the stick if you packed the sqlite. Not Honcho. Not chat history. Not a persona.

This node ships one sqlite with two corpora already embedded: Omarchy manuals and Hermes docs. 10320 passages. Tool name: search_omarchy.

FTS works with lemonade down. Vector search needs nomic-embed-text-v1.5 on lemonade :13305. Never the chat model. Never unload the chat model for index traffic.

./wire-memory

Replicate

To stand up another GarageAGI node:

  1. A computer that runs programs (a host).
  2. Hermes. Your model. Your keys.
  3. This toolbox on disk. Git, USB, or folder copy.
  4. ./scan-secrets then ./inflate then ./wire-memory.
  5. PROCEDURE.md in order. Local first. Git last. Stop is a step.
  6. One allowed door. “Only this machine” counts.

You will not get this operator’s chat. You will get the kit, the hop contract, and a charged memory module if the sqlite came with the copy. Bring the model.

USB

./pack-persona /run/media/$USER/PERSONAS

On the other box: plug in. Inspect the drive. Then ./inflate. Bring the model.

Never .env, auth.json, pgdata, GGUF. scan-secrets must pass before the pack.

Stick copy may include live Hermes skills from the packing box. Kit copy without skills still has the scripts and the sqlite.

This host’s send path

Omarchy is a host OS on Node 1. It is not The Mesh.

hop-send and bare-foot on this node use Omarchy launch, Hyprland, foot, wl-copy, wtype. They are in the public cut because this node verified them here. A replica on another OS still has the packet law (hop-scope, hops/AGENTS.md). The spawn binary may need a local stand-in. That is a door on that host. Not a new protocol.

Minimum

Minimum to run a smart node like this one:

  1. A computer that runs programs.
  2. Hermes.
  3. A model you bring.
  4. Disk for files.
  5. A note: who, what, which files.
  6. One door you allow.

Minimum for The Mesh around it: a second node, both keep a copy of how to read the note, one allowed path between them. A USB stick is enough. GitHub is enough.

Not required: Discord, radio, a server that is always on, Omarchy, two agents, encryption, a new protocol, Honcho, a house costume.

Terms we keep

The Mesh
computers talking; an overlay
overlay
a logical network on networks computers already use
node
a machine that can create, receive, or transmit on a network
host
a node that runs applications. Every host is a node. Not every node is a host
agent
a program that acts for a user
smart node
a host running an agent. Descriptive. Not a standard
packet
the short note: who, what, which files
door
the allowed way to talk
store-and-forward
hold now, send later. GitHub, an SD card, a lean Pi. No agent required
toolbox
the files that say how to read a packet and which local tools to run

FAQ

Is this The Mesh page?
No. The Mesh page is the concept. This is Node 1.
Do I need Omarchy?
This node used it. The packet does not. hop-send on this box does.
Do I need Acid Burn?
No. Costume is out of the public kit. You bring the model.
Is Honcho the memory module?
No. Honcho is peer notes about a person. The module is search plus sqlite.
Why hops?
So work can leave a full context and come back as a short note. Disk holds the files. The packet names them. That is a round trip.
Where is the seed?
CONTRACT.md and TOOLBOX.md in the toolbox. Mesh-Node/mesh-node is the public concept seed.
